# Playwright Assignment

This repository contains my QA automation assignment, covering manual testing, API testing, and UI automation.

## 📁 Project Structure

```
playwright-assignment/
├── manual_test/          
│   └── OrangeHRM_Manual_Test_Cases...
├── postman_assignment/   
│   ├── API_Automation.postman_collection.json
│   └── README.md

```

## 🧩 Assignment Overview

| Module | Description | Tooling |
|---|---|---|
| Manual Testing | Manually designed test cases for OrangeHRM | Excel |
| API Automation | Automated API tests for backend endpoints | Postman |
| UI Automation | Automated end-to-end browser tests | Playwright, JavaScript |

## 🛠️ Tech Stack

- **Playwright** – UI test automation
- **Postman** – API test automation
- **Node.js** – Runtime for Playwright tests
- **JavaScript** – Scripting language
